# Kristopher Villafuerte — Portfolio

Personal portfolio site for virtual assistant and performance marketing work.

## Structure

```
portfolio/
├── index.html        Main page (all CSS and JS are inline, no build step)
├── images/
│   └── kpi-agoa.png  KPI results chart for the flagship case study
└── README.md
```

## Run locally

Open `index.html` in any browser. No server or build tools needed.

## Deploy with GitHub Pages

1. Push this folder to a public GitHub repository.
2. In the repo, go to Settings, then Pages.
3. Under Build and deployment, set Source to "Deploy from a branch".
4. Choose the `main` branch and the `/ (root)` folder, then Save.
5. The site goes live at `https://USERNAME.github.io/REPONAME` within a minute or two.
